# Reference rationale

The reference enumerates all simple directed paths for each sealed order and jointly selects either one complete path or rejection. It tracks shared lane loads and charges each lane opening fee at the first accepted use. The comparison key is the negative priority-count tuple, total operating cost, then the ordered lane-ID path descriptor by sorted order ID. The final output is reconstructed in input order and checked against lane capacities.

The five independent challenge groups are:

- `PRI-01`: maximize accepted counts by priority as a lexicographic tuple (`test_hand_computed_dispatch_respects_priority_and_open_fee_gate`, `test_exhaustive_small_ledgers_match_independent_joint_enumeration`, `test_unreachable_order_is_rejected_without_changing_other_service`). The natural gate uses a hand-derived case where accepting a lower-priority order would conflict with a higher-priority whole-order shipment.
- `CAP-02`: joint shared-capacity feasibility with all-or-nothing pallets (`test_whole_order_cannot_be_split_across_individually_insufficient_paths`, `test_partial_capacity_assignment_prefers_feasible_order_subset`, `test_exhaustive_small_ledgers_match_independent_joint_enumeration`). The oracle independently enumerates simple paths and every order/path/rejection combination, then checks aggregate lane loads.
- `FIX-03`: fixed lane-opening fees and variable pallet charges (`test_shared_lane_fee_is_paid_once_for_multiple_orders`, `test_opening_fee_can_overrule_individually_cheapest_lanes`). The assertions recompute one fixed fee per used lane and per-pallet cost for every order segment.
- `TIE-04`: stable global selection among equal service and cost plans (`test_tie_break_uses_lane_ids_not_input_lane_order`, `test_tie_break_is_stable_under_order_input_permutation`). The expected descriptor is derived independently from the public ASCII ordering rule.
- `VALID-05`: strict input, stable plan semantics and atomic publication (`test_rejects_duplicate_json_key_without_creating_output`, `test_rejects_boolean_capacity_and_preserves_sentinel`, `test_rejects_fractional_integer_field`, `test_rejects_duplicate_identifier_and_late_invalid_order_atomically`, `test_atomic_replace_failure_preserves_old_report`, `test_identical_input_produces_identical_plan`). Rejections check absent output or byte-preserved sentinel and no staging artifact.

`test_contract.py` contains 16 discoverable tests, with one natural gate and 15 weighted cases normalized to 1.000. The small-instance oracle does not call the candidate solver. `assert_plan_consistent` separately checks path continuity, non-repeated nodes, order indivisibility, lane capacities, service counts, fixed fees, variable costs and output order.
