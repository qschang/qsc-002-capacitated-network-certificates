# Reference rationale

The reference first validates the complete input and rejects a negative-cost directed cycle on positive-capacity arcs. It then computes a minimum-cost maximum flow over paired forward/reverse residual arcs. The returned edge-flow vector is the primal witness. The `source_side` cut independently certifies maximum throughput, while `node_potentials` certify minimum cost: every residual arc has nonnegative reduced cost within the public tolerance.

The six independent challenge groups are:

- `OPT-01`: maximum throughput, conservation and min-cut equality (`test_optimum_and_complete_primal_dual_certificate`, `test_residual_rerouting_finds_a_full_flow`, `test_unreachable_sink_has_zero_flow_and_valid_cut`). The first natural gate checks a hand-derived optimum and directly checks every primal and dual certificate relation.
- `OPT-02`: minimum total cost among all maximum flows, including legal negative edges (`test_exhaustive_small_networks_match_independent_flow_enumeration`, `test_negative_edge_cost_without_negative_cycle_is_optimized`). The small-network oracle enumerates every integral edge-flow vector and independently selects maximum value followed by minimum cost; the tests also recompute the submitted objective.
- `OPT-04`: parallel lanes, zero versus strictly positive capacity, and input-position identity (`test_parallel_edges_keep_separate_costs_and_input_positions`, `test_every_positive_capacity_participates_and_zero_capacity_does_not`). Expected lane choices follow directly from capacities and unit costs.
- `CERT-03`: full primal feasibility, cut certificate, and residual reduced-cost inequalities (`certificate_issues`, exercised by the optimum, enumeration, rerouting, signed-cost, boundary, unreachable and scale tests). The checker derives balances, objective, residual directions, and cut from the input and candidate output, not from reference residual state.
- `VALID-04`: cycle scope, duplicate names, late rejection, atomic replacement and deterministic repeat (`test_rejects_negative_cycle_even_when_disconnected_and_preserves_output`, `test_rejects_reachable_negative_cost_self_loop`, `test_rejects_duplicate_json_keys_without_publication`, `test_late_invalid_edge_preserves_sentinel_and_leaves_no_temporary_file`, `test_atomic_replace_failure_preserves_old_plan`, `test_identical_runs_produce_semantically_identical_results`). Rejections are checked against absent-output and/or byte-preserved-sentinel states as applicable.
- `PERF-05`: 2,048-node, 16,384-edge layered workload within the public latency bound (`test_public_scale_finishes_and_returns_a_checkable_optimum`). The expected throughput and cost are derived from the two unit source lanes and 255 negative-cost layers crossed by each delivered unit.

All score groups map to public behavior. The exhaustive oracle only uses tiny integral-capacity instances, where enumerating every edge-flow vector is independent of the residual algorithm. The large fixture has an analytic objective and is not used as the sole correctness oracle.
